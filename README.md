# Devocional BOT — Releases

Repositório público de distribuição do **Devocional BOT**.

Contém os instaladores e os arquivos de atualização automática de cada versão.
O código-fonte do app fica em repositório privado separado.

## Instalação

Baixe o arquivo `.exe` da release mais recente e execute o instalador.

## Atualizações

O app verifica atualizações automaticamente uma vez por dia.
Quando uma versão nova estiver disponível, um aviso discreto aparece no app.
A instalação só acontece quando você decidir.
